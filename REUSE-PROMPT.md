# Shared reference handoff

Use this library for any current or future project, irrespective of domain. Read `AGENTS.md`, the selected source's `README.md`, `COVERAGE.md`, `PROVENANCE.md` and interaction notes before changing the application.

Start with `REFERENCE-MAP.md` when the user describes a need without naming a website. shadcn/ui is the baseline for restrained, polished functionality; Viewport and 60fps provide broader visual/motion discovery, while Interior, Motion Primitives, Cult, React Bits, Bencho and Aceternity provide their documented/source-backed patterns. Do not restrict discovery to named favorites.

Find the relevant component in the full catalogue; do not limit discovery to the favorites list. Preserve the original construction, geometry, typography, motion, transitions, direct pointer response and state recovery when the project requests faithful behavior. Record the exact component, variant, revision and selected props. Read computed formulas at their source links; never guess precision timings from a still.

Bencho's redistributable free snapshot is under `bencho/upstream-free`. React Bits source is local under ignored `.local/react-bits`, with pinned original links in `reactbits/components`; do not publish it as a component collection. Preserve applicable licenses and third-party notices. Pro previews and third-party Finds are references, not permission to copy restricted source or redistribute media.

Other official source snapshots are under `.local/upstream/<site>` with hashes and pinned links in each source index. Aceternity's public implementation cache is not a redistributable library; 401/403 registry entries remain restricted. Gallery media and private observation captures are not published assets.

Keep a complete action sequence: initial state, focus/hover, press, drag, threshold, release, completion, cancellation, reverse path, reset and repeated action. Use the browser/assertion records as evidence of what was actually checked, not a promise of exhaustive verification. Test the chosen behavior with the consuming application's real routes, permissions, validation, storage and async failures. Demos do not establish authentication, file persistence, deletion, audio recording or payment success.

Maintain professional, clean, concise UI. Avoid decorative emoji, filler paragraphs, implementation explanations and routine workflow narration. Preserve accessibility labels, useful validation and essential decision warnings. Check keyboard, touch, reduced motion and actual responsive behavior. Catalogued backgrounds remain available, but do not select a portfolio background without the user's direction.

Keep reusable facts in this shared repository and project choices under `projects/`. Do not silently apply one project's decisions to others. Authorization to maintain and push this reference repository does not authorize commits, pushes or rebases in application repositories.
