# Aceternity interaction and access notes

The public catalogue spans components, blocks, pages, interactions and templates. The registry lists 321 items: 121 returned public source in this research and 200 returned HTTP 401. A public preview or registry name does not establish authorized access to its implementation. Restricted entries remain in the catalogue with that boundary.

The 121 public-source guides retain API structure, dependencies, motion/default values and source hashes. Source is cached locally for reference and not redistributed here. Aceternity's license distinguishes use in end products from redistribution of the items or a template/component collection. Read the original terms for the selected item before integrating or distributing it.

## Behavior families

- Spatial cards, pins, globes and parallax: preserve pointer coordinate normalization, transform origin, perspective, depth ordering, clipping and pointer-leave recovery. A hovered screenshot does not specify these calculations.
- Backgrounds, beams, sparkles, shaders and moving borders: preserve animation uniforms/tokens, repeat behavior, masking, pixel density and disposal. Test performance, reduced motion and static fallback on the target device.
- Text generation, flipping, reveal and scramble: retain segmentation, timing order and interruptions when content changes. A demo's fake generating state is not a real service request.
- Hover effects, tooltips, docks and menus: preserve target geometry, hover gaps, focus, dismissal and touch alternatives. Do not make essential navigation hover-only.
- Carousels, galleries, compare sliders and interactive grids: keep selected item, drag offset, inertia, snapping and committed callbacks distinct. Image loading and dimensions can change layout and must be tested.
- Hero, bento, pricing, navigation, login and contact blocks: retain responsive structure and visual hierarchy, then wire real routes/forms. A polished block is not a complete application flow.
- Paper-plane, paper/material and other paid interaction previews: record observable phases and creator/source links; do not infer hidden physics or access restricted code.

Do not copy placeholder content, real people's endorsements, stock imagery or marks into a project merely because they appear in a demo. Use the actual project's content and permitted assets. Match requested motion and formation without publishing the source collection as a competing library.
