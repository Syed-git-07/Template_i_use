# Expanded reference research

Requested 17 November 2026. The public inventory/source-reference research pass is complete and validated. This is not a claim that every possible interaction, device, paid source or production integration was exhaustively verified.

Order: Viewport UI → 60fps → shadcn/ui → Interior → Motion Primitives → Aceternity UI → Cult UI → React Bits remaining gaps.

## Delivered evidence

- 4,836 indexed public pages across the seven new sites, with complete discovery lists and per-page evidence ledgers.
- 414 component source guides and 32 additional 60fps snippet guides.
- 3,542 original source/document files verified against saved hashes; 64 deduplicated 60fps code blocks retained locally with hashes.
- 785 component/documentation browser observations across shadcn, Interior, Motion Primitives, Aceternity and Cult.
- All 624 Viewport posts observed: 375 recordings sampled and 249 images observed. Named priorities have denser samples, including the contact form's submission sequence.
- All 2,317 selected 60fps shot/motion URLs have media observations. These include collection/filter pages where present; do not call this a count of unique original animations.
- Nine selected new-library gesture scenarios passed, comprising 13 assertions. Four additional React Bits scenarios passed with five assertions under mobile/touch emulation and reduced motion.
- Local links, catalogue/evidence consistency, pinned source hashes and staged publication boundaries validated.

## Remaining limits

Aceternity has 200 restricted registry sources; 60fps's full Storyboards require Pro. These were not accessed. Three Aceternity pages and six Cult pages retained client-side rendering errors after targeted retries; their records identify the exact pages. All requested browser pages loaded, but rendering a page is not certification of every demo state. Gallery samples do not disclose exact easing, hidden error behavior or font-file identity. Read each study's COVERAGE before reusing it.

Original implementation caches and media observations remain under ignored `.local/`; the published repository contains permitted notices/contracts, authored notes, factual API/source metadata and links. No portfolio implementation, commit or push was performed.

Preserve complete public discovery and catalogue inventories, then source/API/motion evidence and selected runtime sequences. Distinguish source-backed exact values from video observations and unavailable implementation. Never label an inventory as exhaustive behavioral verification.
