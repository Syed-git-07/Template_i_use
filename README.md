Keep layouts professional, text concise, and motion purposeful. Preserve anticipation, pointer response, shape continuity, interruption, release and recovery. Do not substitute generic animation or add decorative emoji, filler text or unnecessary instructions.

Approved references include all studies linked above, plus [Control UI](https://control-ui.dev/components) and [Fancy Components](https://www.fancycomponents.dev/components), which do not yet have full studies here. Consult each study's coverage rather than assuming that a catalogue or source index certifies every interaction.

shadcn/ui is the user's minimum baseline for clean, professional, complete interfaces. Use this collection proactively even when the user cannot remember the site or component name. Viewport's [letter/envelope contact form](viewport/INTERACTIONS.md) is a specific portfolio reference; the portfolio remains in the research stage.

React Bits includes 217 public components, 64 of which are backgrounds, plus two unlisted source components. Its 219 guides preserve API facts and pinned implementation links. Unlike Bencho's MIT free snapshot, React Bits implementation stays local and excluded from Git because of its Commons Clause redistribution restrictions. Read each study's coverage before reuse.

Keep shared reference facts with their source. Keep project-specific decisions under `projects/`; portfolio choices must not silently become rules for unrelated applications.
